# Go API reference

Import github.com/softdevstudio/ebyte. The pinned compiler is specified in go.mod. Schema, document, trace and diagnostic formats are version 1; the package's release version is separate. The executable example in example_test.go compiles an external caller, decodes independent bytes, edits an array and encodes a derived count.

Compile(schemaBytes []byte, limits Limits) returns (*Plan, error). Start with DefaultLimits() and lower selected ceilings; zero is an actual ceiling. The compiler owns validated strings, retains no caller buffer and resolves bounded same-object dependencies. Plan has no exported mutable execution state and can be shared across concurrent operations with separate readers/writers. Name(), SchemaSHA256() and Limits() return metadata/copies. Schema identity covers exact bytes, including whitespace.

Plan.Decode(ctx context.Context, reader io.Reader) returns (*Document, *Trace, error). A success has both results. Failure always has a nil document and can have a labelled failed trace; the trace is nil if its failed envelope cannot fit its byte ceiling. Plan.Inspect(ctx, reader) returns (*Trace, error) using exactly the same validation, currently materializing/discarding editable values too. Both value and trace budgets apply. EOF/trailing data is checked, so no undeclared bytes are discarded.

Plan.LoadDocument(ctx, rawJSON []byte) returns (*Document, error), strictly parsing and validating editable JSON against the plan. Plan.Encode(ctx, document *Document, writer io.Writer) returns error and revalidates caller edits. It prepares bounded binary bytes before writing; all validation failures write nothing. Short/failed writes and cancellation during/after Write can leave output that callers must discard. LoadDocument prepares and discards binary bytes for validation; Encode prepares them again. Encode applies document/output budgets, not decoder-only input/trace budgets.

Document.Values is map[string]any. Integers are canonical decimal strings, bytes are lowercase hex strings, text is valid exact-width ASCII/UTF-8, arrays are non-nil []any containing non-nil map[string]any objects. Empty values are allowed when declared; nil/null is not a replacement for absence. Derived counts and inactive conditional fields must be omitted. Returned documents/traces belong to the caller and may be edited, but must not be modified concurrently with use or serialization.

Errors are *Diagnostic and can be found with errors.As. Code/stage/path and nullable offset/field_start are specified in errors-v1.md; never infer unknown offsets from zero. Trace entries disclose observed integers but no raw byte/string values. Known encode assertion/ASCII positions refer to prepared bytes, not a guarantee that output was written. Default diagnostics do not include arbitrary reader/writer error text or filenames.

Pass non-nil contexts and readers/writers obeying Go's I/O contracts. Cancellation checks cannot interrupt arbitrary blocked library Read/Write calls. The CLI adds process-level stdin interruption and file staging; the library makes no atomic-publication guarantee for a supplied writer. JSON output materializes in bounded memory and may allocate many times the binary input size across a complete pipeline. See schema-v1.md, document-v1.md, errors-v1.md and testing.md for exact bounds and evidence.
